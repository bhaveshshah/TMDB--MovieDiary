  An interactive movie diary application powered by The Movie Database (TMDB) API. Browse movies, mark your favourites, and manage your personal collection with ease.
</p>

---

## ✨ Features

- 🎥 **Browse Movies** – Discover a wide range of movies fetched from the TMDB API
- ⭐ **Mark Favourites** – Add movies to your favourites list with a single click
- ❌ **Remove Favourites** – Easily manage and remove movies from your collection
- 💾 **Persistent Storage** – Your favourites are saved locally using localStorage
- 📱 **Responsive Design** – Seamless experience across desktop, tablet, and mobile devices
- ⚡ **Fast & Lightweight** – Built with vanilla JavaScript and Tailwind CSS

---

| Technology            | Purpose                                                  |
